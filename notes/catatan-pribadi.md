# 📝 Catatan Pribadi Project & Handover

Aplikasi web personal untuk tracking tiket **XLWO & RFC**, monitoring masa berlaku SLA & reminder dini, mengelola status site ( `done` , `partial` , `pending` ) dan kebutuhan lain terkait ticketing project (temporary XLWO only).

Dirancang **mobile-first (PWA)** sehingga bisa langsung dibuka di browser HP (Chrome, Safari, Firefox) tanpa perlu install aplikasi Android APK. serta agar bisa dipakai untuk mempermudah pekerjaan orang pengganti cuti saya :D

---

### Catatan Tambahan & Handover Operasional:
- Target Uniq: ~198 Uniq
- Format Tiket:
  - `XLWO-YYYYMMDD-XXXXXXXX` (SLA 7 Hari, Reminder H-5)
  - `RFC-YYYYMMDD-XXXXXXXX` (SLA 27 Hari, Reminder H-25)
- Folder `notes/` ini sudah terdaftar di `.gitignore`, sehingga aman diedit kapan saja tanpa takut tertimpa saat update aplikasi.
