Modul ini disiapkan untuk data realtime yang nantinya akan kamu upload/stream. Terhubung ke status CSR, IP Loopback, Latency, dan BGP status.

💡 Tips: Nantinya kamu bisa upload data JSON atau CSV telemetry berkala lewat script, curl, atau form upload, dan dashboard ini langsung update realtime tanpa reload!

💾 Backup & Restore Mandiri

Simpan seluruh database tiket dan konfigurasi ke file backup JSON, atau restore kapan saja jika ada perubahan.

🔥 Hubungkan Google Firebase (Realtime Sync)

Cukup salin dan tempelkan firebaseConfig dari Firebase Console di bawah. Layar HP dan Laptop kamu akan langsung terhubung realtime via Google Firestore!

🛠️ Panduan Singkat 1 Menit Ambil Config di Firebase:
  1. Buka console.firebase.google.com dan buat project baru (gratis).
  2. Klik Build ➔ Firestore Database, pilih Create Database (pilih "Start in test mode").
  3. Buka Project Overview (ikon roda gigi ⚙️) ➔ Project settings.
  4. Scroll ke bawah ke bagian "Your apps", klik ikon Web `</>`, beri nama web, lalu salin blok firebaseConfig ke kotak di atas!
